VDO53003 接收零跑M+1计划排产信息接口文档

## 1. 接口说明

| 项目         | 内容                                   |
| ------------ | -------------------------------------- |
| 接口名称     | 接收零跑M+1计划排产信息                |
| 接口编号     | VDO53003                               |
| 接口类型     | 接收外系统数据接口                     |
| 接口方向     | 零跑系统 → VDO系统                     |
| 调用方式     | HTTP POST                              |
| 数据格式     | application/json                       |
| 是否支持批量 | 是（支持多条数据一次性传入，逐条处理） |

## 2. 接口地址

| 环境 | 地址                                                         |
| ---- | ------------------------------------------------------------ |
| SIT  |                                                              |
| UAT  | **https://uat-api.faw.cn:30443/JT/MA/MA-0203/001/IVDO/receiveM1Data** |
| PROD | **https://api.faw.cn/JT/MA/MA-0203/001/IVDO/receiveM1Data**  未发布 |

## 3. 请求头参数

| 参数名 | 类型 | 是否必填 | 说明 |
--------|------|----------|------|
| Content-Type | String | 是 | 固定值：application/json |
| Authorization | String | 否 | 鉴权令牌（按各环境要求传递） |
| Accept-Language | String | 否 | 语言标识，如 zh-CN |

## 4. 入参模型

入参为数组，每个元素结构如下：

| 字段名           | 字段标识        | 类型   | 是否必填 | 说明                                     |
| ---------------- | --------------- | ------ | -------- | ---------------------------------------- |
| PO单号           | poNo            | String | 是       | 零跑采购订单号                           |
| SO单号           | soNo            | String | 是       | 零跑销售订单号                           |
| VIN              | vin             | String | 否       | 车辆识别代号                             |
| 18位零跑物料编码 | lpMtlNo         | String | 是       | 零跑18位物料编码                         |
| 预计总装下线日期 | planOfflineDate | String | 否       | 格式 yyyyMMdd，用于状态推进与计划周更新  |
| 实际总装上线时间 | actOnlineTime   | String | 否       | 格式 yyyyMMddHHmmss，有值触发状态 HQ5700 |
| 实际总装下线时间 | actOfflineTime  | String | 否       | 格式 yyyyMMddHHmmss，有值触发状态 HQ6200 |

## 6. 出参模型

返回为数组，每条入参对应一条出参，结构如下：

| 字段名           | 字段标识 | 类型   | 说明                                     |
| ---------------- | -------- | ------ | ---------------------------------------- |
| PO单号           | poNo     | String | 回填入参的 PO单号                        |
| SO单号           | soNo     | String | 回填入参的 SO单号                        |
| 18位零跑物料编码 | lpMtlNo  | String | 回填入参的 18位零跑物料编码              |
| VIN              | vin      | String | 回填入参的 VIN                           |
| 是否接收成功标识 | isSign   | String | Y：接收成功；N：接收失败                 |
| 错误消息         | errMsg   | String | 失败时的错误说明（含具体单号，便于排查） |

## 7. 返回值格式（JSON 示例）

### 处理成功

```json
{
  "result": true,
  "success": true,
  "message": "操作成功",
  "res": [
    {
      "poNo": "PO2026060001",
      "soNo": "SO2026060001",
      "lpMtlNo": "LMT000000000000001",
      "vin": "LZWADAGA1P1000001",
      "isSign": "Y",
      "errMsg": ""
    }
  ]
}
```

### 处理失败（含失败明细）

```json
{
  "result": true,
  "success": true,
  "message": "操作成功",
  "res": [
    {
      "poNo": "PO2026060009",
      "soNo": "SO2026060009",
      "lpMtlNo": "LMT000000000000009",
      "vin": "LZWADAGA1P1000009",
      "isSign": "N",
      "errMsg": "PO单号PO2026060009未查到对应订单主数据（PO单号）"
    }
  ]
}
```

## 8. 错误报文

### 系统级错误码

| 错误码 | 含义       | 处理建议      |
| ------ | ---------- | ------------- |
| 200    | 操作成功   | -             |
| 500    | 服务端异常 | 联系 VDO 运维 |
